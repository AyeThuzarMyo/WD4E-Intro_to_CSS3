# week1-css-HW1

## Description
A simple multi-page website built with HTML and CSS as part of the 
"Web Design for Everybody" Coursera specialization (Week 1 CSS assignment). 
The site showcases photos from dog walks around Ann Arbor, Michigan, 
featuring three pages: Home, Neighborhood Walks, and Walks in the Park. 
Each page shares a common navigation header and footer.
